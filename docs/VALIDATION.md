The automated suite covers single-use pairing/local confirmation, required authentication/CSRF/Origin, session revocation, rejected WebSockets, literal loopback model endpoints and rejection of external inference machines, path traversal/secret/symlink denial, strict action parsing, stale observations/wrong focus/invalid coordinates, Retina/resized-window coordinate transforms, denied password/browser typing, task idempotency, ordered events, exact approval digest/generation binding, takeover, pause during pending inference and preflight, cancellation before desktop dispatch, task deadline, worker restart without replay, clean-original requirements, diff hash/content conflict rejection, exact apply, loopback preview/CSP boundaries, artifact authorization, and the independent cart harness. The reliability revision adds staged prompt compaction and refusal, element-target resolution and re-check, the scroll point inside the approved window, rejection of truncated output or exhausted context, recorded token/latency metrics, and bench grading and private report writing.

Browser QA caught and fixed a phone layout overlap before final testing. Final mobile layout prioritizes the screen during tasks and keeps a Stop button in the top bar. QA generated only local test screenshots; none are presented as screenshots of the user's Mac.

`ghostdev doctor` in this environment accurately reports native desktop unavailable and model endpoint unreachable (exit 2), and `ghostdev bench` exits 1 with "Local model server unreachable"; neither manufactures readiness. The runtime has no selectable fake/model-demo mode. Tests live under `tests/` and are explicitly separated from physical evidence.

Dependency audit from October 11: the frontend tree reported transitive build-tool advisories rooted in braces and node-forge, whose published registry versions were not outside their reported advisory ranges. uuid and decode-uri-component are pinned to patched overrides. See PERMISSIONS.md. This is a hackathon MVP and is not certified for unattended use of personal desktops.

Before calling the project a successful local desktop demo, complete docs/DEMO.md on the actual MacBook, record the real model/runtime/evidence, and rehearse with internet egress blocked and LAN connectivity retained.

The Mac-only revision also tests the non-NVIDIA default model, local port 11434, thinking/context payload settings, and migration from a previous remote endpoint while preserving project/phone settings. The model server must be local; no separate inference machine is required.
